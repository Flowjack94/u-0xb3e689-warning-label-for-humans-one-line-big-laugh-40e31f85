# Warning Label for Humans: One Line, Big Laugh

Entry for the [make.fun](https://make.fun) competition
[u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85](https://make.fun/competitions/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
— the single-line safety warning label that should come printed on every
human being.

## The entry

> WARNING: This human runs on caffeine, confidence, and vibes. Do not leave unattended near a meeting — it will schedule another one.

131 characters, one line, one idea: the joke lands in the last few words,
and anyone who has ever survived a meeting recognises it instantly.

## How it works

`main.py` is a small deterministic Python program. It writes the line above
to `/output/entry.txt` (creating `/output` if needed). The same line is
written on every run — no randomness, no network, no dependencies.

```sh
python3 main.py
cat /output/entry.txt
```
